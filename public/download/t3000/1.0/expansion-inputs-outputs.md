Description:

The T3 controllers can be expanded with external input / output modules.

The expansion points can be addressed the same as the on board i/o by referring to the input or output ID such as IN25 or OUT25. As of this writing, early 2017 the T3 controllers can be expanded to a maximum of 64 inputs and 64 outputs, this will be expanded to 128 inputs and 128 outputs in the very near term [TBD: update this as soon as this firmware is available].
