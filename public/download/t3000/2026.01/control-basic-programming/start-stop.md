---
title: "START, STOP"
order: 1070
---

Purpose:
To set a value of a variable to 1. Normally used to turn an output on. Also, normally only used with items which are configured as binary, ON-OFF for the range.

Format:
START variable

Examples: 10 START OUT1

20 START A

30 START VAR1
