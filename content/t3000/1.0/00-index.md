Test1 is the controller every later Temco product was measured against: a small, fixed set of inputs and outputs, one
program, and a display that says what the machine is doing. This documentation covers the version you are holding, and
nothing else — each version keeps its own pages, so a machine commissioned two years ago still reads correctly.

## What this version covers
- Wiring an input and proving it changed
- Pointing a port at the right device
- Writing and downloading a program
- Reading the alarm log, and clearing an alarm that has gone

## What it does not cover
Networking and protocol work belong to [BACnet](#/bacnet/1.0/index) and the tools that speak it. If you are looking for how
a supervisor reads these points, start there rather than here.

> Every page in this version was written against firmware 1.0. A page that only applies to a later build says so at the top.
