Minimal System Requirements

The T3000 application is not particularly demanding on the CPU, a bare bones Win10 system will run the application just fine. There is no linux or Mac version of the software. Windows XP is no longer supported.

- •
  Microsoft Windows 8 thru Win10
- •
  SVGA or better, color display
- •
  1Ghz Hz processor
- •
  1G RAM
- •
  2 GB free hard drive space
- •
  Ethernet
- •
  USB to RS485 converter is recommended for testing RS485 communications.
